RULE-BASED DETECTION

Detection Rules

Current rules used by the C++ analysis engine.

Repeated Authentication Failures

Flag an account when it reaches at least three failed login attempts in the analyzed log.

Consecutive Failure Detection

Flag an account when its longest consecutive failed-login streak reaches three.

Severity Classification

HIGH: a failure streak of at least three or at least five total failed logins. Other flagged accounts are classified MEDIUM by the current rules.

DATA QUALITY

Log Validation

Username Validation

Usernames are checked against the engine's allowed character rules and maximum length.

Record Validation

Invalid or malformed rows are counted separately from successful and failed login records.

Local File Processing

The browser sends log content to the local Python backend, which invokes the C++ analyzer.

PROJECT INFORMATION

About ThreatLens

ThreatLens is a local authentication-log analysis demonstration built with C++, Python, HTML, CSS, and JavaScript.

Technology Stack

C++ · Python · HTML · CSS · JavaScript

Purpose

Demonstrate log parsing, input validation, rule-based detection, and security-report generation.

Detection results are indicators based on configured rules. They do not independently prove malicious activity.
